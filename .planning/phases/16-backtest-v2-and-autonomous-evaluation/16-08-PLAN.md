datafeed/transport.py (new, the only module that opens sockets in this plan):
- `make_read_transport(endpoint: str) -> ReadTransport`: the only socket factory. Validates the endpoint with readonly._validate_endpoint, then builds an httpx-backed JSON-RPC transport.
- `RecordingWebSocket`: wraps the websocket async iterator; for each frame it calls recorder.record_frame(frame) before yielding the frame. Drops API-key headers and replaces query parameters named api-key, key or token with REDACTED (paper-engine.md section 4.4; the G-3 secret regex set).
- `RecordingJsonRpc`: wraps a ReadTransport; records each request method and each response through record_frame before returning the response. Calls go through ReadOnlyBoundary, which refuses any method not on its allowlist.
- No LLM client.

datafeed/feed_loop.py (new):
- `record_session(dataset_dir, *, duration_s, mints, clock, transport, recorder_factory)`: runs build_live_paper_root in mode paper with the recorder at dataset_dir for duration_s on the wall clock, with the recording wrappers around the transport; seals with LiveRecorder.seal on exit, closing open gaps. Returns the sealed directory.
- `serve_once(*, endpoint, transport, clock, data_dir, budget, limits, ...)`: builds the live paper root in mode paper and runs exactly one supervisor cycle. Without --once, the same loop runs until SIGTERM or SIGINT, then exits 0.
- Neither function imports a live adapter, signing module or key reader.

cli/parsing.py:
- run: add `--mints <comma-separated list>` (optional). Keep existing `--record`, `--duration`.
- live: add subcommand `serve` with `--rpc <url>` (required, no default) and `--once` (store_true).
