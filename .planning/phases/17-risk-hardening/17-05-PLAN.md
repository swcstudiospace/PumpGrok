digest and the idle test on a fake Clock. The e2e uses only recorded
fixtures and the replay Grok backend, so it runs without network. A
skipped e2e fails the phase, so no test may be marked skip.

live_paper root behaviour. The golden digest file is deleted with the
e2e test; no ledger migration is involved.
