The override check at bounds.py:146-149 (`value < bound.minimum or value > bound.maximum`) is also False for NaN, so a NaN override is accepted.
- Evidence binding (S-P2): `BacktestEvidenceProvider.feed_promotion` (src/pumpgrok/backtest/evidence.py:51-70) takes `verdict`, `params_hash` and `apply_kwargs`, and passes them to `apply_candidate` without binding them to a candidate hash. `EvidenceRecord` is at evidence.py:27-35. - Writer guards: `is_writer` (src/pumpgrok/ledger/active_set.py:74), `verify_stored_content` (line 154). Existing caller: src/pumpgrok/upgrade/rollback.py:61-63.
- Name collision: `src/pumpgrok/cli/promotion.py` exists (the upgrade check, wired by cli/verbs_state.py:30 and :120). The new `promotion demote` verb and the new package must not reuse its names.
- Threshold file location: the package config convention is `src/pumpgrok/config/upgrade_bounds.toml`. Use `src/pumpgrok/config/promotion_thresholds.toml` (index Finding 5).
- Decisions: D17-3 (thresholds from the toml; looser refuses to load; paper window from the first paper fill; zero-loss rule). PRM-05 (no timers, no Grok) is enforced in 17-05. No file in this plan may contain the literal strings `clock.sleep` or `pumpgrok.grok`, including in comments, because criterion 8 greps the promotion package as text.
