Recorder amendment (live_recorder.py):

- Add `LiveRecorder.record_frame(raw: dict[str, object])`: writes one canonical JSON line `{"ts": <Clock ts>, "stream": ..., "payload": ...}` to feed.jsonl through the existing `_append_record`. It is additive: no existing method signature changes. supervisor/live_paper.py constructs `LiveRecorder(dir, clock=...)` and must not need an edit. If it does, STOP and report to CHIEF.
- Ordering contract, documented in the docstring: a frame is durable in feed.jsonl before the observation it produces is appended to events.jsonl. The caller (16-08 transport wrapper) calls record_frame before the frame reaches the bridge.
- Factor the manifest write and load_dataset acceptance out of `LiveRecorder.seal` into one module-level helper `seal_directory(dataset_dir, *, recorded_from_utc, recorded_to_utc, sources, notes)`. LiveRecorder.seal calls it. maintenance.py calls it too. One sealing path.
- No network, LLM or RPC import in replay/.

Maintenance module (replay/maintenance.py), each function deterministic:
- `trim(source_dir, *, max_events, seed) -> Path`: (1) replay the full source dataset with run_once_replay into a temporary directory (source replay, offline; the ledger is discarded after reading) and collect the mints that have an order row; (2) walk events.jsonl in file order with one random.Random(seed); an event whose mint has an order is kept; any other event is kept when rng.random() < 0.05, and the rng is drawn only for those events; (3) keep the last max_events of the kept events; (4) write events.jsonl, copy gaps.jsonl unchanged when present, omit feed.jsonl, and seal via seal_directory into var/datasets/<name>-trimmed/. Refuse an existing target. Inserts no gap rows.
- `rebuild_ticks(source_dir) -> Path`: refuses a source without feed.jsonl (CorruptFixture, names the missing feed). Reads feed.jsonl only, never events.jsonl or any other derived file. Replays the frames in (ts, file_order, line_no) order through the same datafeed frame handling the live path uses (datafeed/portal.py, datafeed/logs.py and build_observation_bridge), with a clock set to each frame's ts and a recorder writing to a temporary directory. Copies feed.jsonl and gaps.jsonl, seals into var/datasets/<name>-rebuilt/. If that frame handling needs a transport or a wall clock to process a frame, STOP and report; do not substitute a new derivation.
- `import_dataset(ledger_path, *, name) -> Path`: refuses a name failing DATASET_NAME_RE; opens the ledger with LedgerStore read-only; requires verify() true from GENESIS_PREV_HASH and every row's source in {"paper"} (SOURCES is {paper, replay, manual}; only paper passes); refuses an existing var/replay/<name>/; copies the file bytes unchanged to var/replay/<name>/imported-ledger.sqlite; writes var/replay/<name>/imported-ledger.sqlite.sha256 in sha256sum form `<hex>  imported-ledger.sqlite`. Nothing is converted. Replayability of an import is not defined here (owner confirmation F).

Routing and parsing:
- parsing.py: replay trim gains `--dataset <name>` (required), `--max-events <N>` (int, required, positive) and `--keep-mints-with-fills` (store_true, required by the verb: the only keep rule). rebuild-ticks gains `--dataset <name>` (required). import gains `--from <ledger.sqlite>` (required) and `--dataset <name>` (required). Do NOT add run --record or live serve arguments here (16-08).
