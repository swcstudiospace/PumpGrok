## Verification note: pytest form

Every `uv run pytest` command in this plan (Acceptance and Verify lines) is run as `uv run python -m pytest <same targets and flags> --junitxml=<absolute path>`. The XML path must be absolute and sit outside the worktree (for example `/tmp/phase20-task2.xml`) so `git status` stays clean. Read the counts from the `<testsuite>` element of that XML: `tests`, `failures`, `errors`, `skipped`. Reason: `pyproject.toml` sets `addopts = "-q --strict-markers"` and the Makefile test target adds `-q`, so `uv run pytest` suppresses the summary line in this environment and its console output is unreliable. The process exit code stays the authority for pass or fail; the XML counts are the evidence.
