## Objective

Create the backtest package with the run manifest: whole-dataset digest,
seed, FilterSettings hash, parameter-set hash and code version, with the run
id derived from the manifest. Per CONTEXT D-01, D-02, D-11 and G-04.

## Task 1: Build run manifest

**Files:** src/pumpgrok/backtest/__init__.py, src/pumpgrok/backtest/manifest.py

**Read first:**
.planning/phases/08-backtest-and-paper-evaluation/08-CONTEXT.md (contracts);
src/pumpgrok/replay/fixtures.py (dataset layout and manifest values);
src/pumpgrok/config/settings.py FilterSettings definition;
src/pumpgrok/core/idempotency.py (canonical JSON precedent);
src/pumpgrok/replay/rng.py (seed source)

**Action:**
Create package `src/pumpgrok/backtest/__init__.py` and
`src/pumpgrok/backtest/manifest.py` exposing exactly the contract names:
`RUN_ID_VERSION`, `dataset_digest` hashing every file in the dataset
directory in sorted-name order with concatenated per-file sha256,
`build_manifest` returning the frozen `RunManifest`, and `run_id` derived
as sha256 over the canonical JSON (sorted keys) of the manifest. Code
version defaults to git HEAD sha with `UNKNOWN-DEV` fallback. Money fields
are not involved; keep all hashes hex strings. No wall-clock timestamps in
the manifest (D-09 flows through this type). mypy --strict clean, ruff
clean.

**Acceptance:** `uv run pytest -q tests/backtest/test_run_manifest.py` exits 0 (test written in Task 2 of this plan)

**Verify:** `uv run pytest -q tests/backtest/test_run_manifest.py`
