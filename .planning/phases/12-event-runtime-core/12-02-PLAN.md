## Objective

Build the typed event runtime library per CONTEXT D-08, D-09, D-10 and G-01 through G-03: typed errors, harness fakes, the single event catalog, EventBus with lanes, sidecar store, persisted DLQ, graceful shutdown, the events CLI and the design doc. Public interfaces are frozen here; later phases only consume them.

## Public interfaces (frozen by this plan)

- errors: EventBusSaturated(PumpgrokError), GrokBudgetDenied(PumpgrokError) in src/pumpgrok/core/errors.py
- harness: FaultyEventSource, FaultyGrokTransport in tests/harness/faults.py
- models: EventKind str enum (Design A kinds TokenLaunched, PriceTick, PositionTick, SourceStatus, Timer, ExitDeadline, Heartbeat, CandidateReady, StrategySignal, GrokVerdict, OrderOutcome, RiskEdge, PositionChange, Migration, LargeTransfer, HolderShift, plus Design B and C kinds CurveTick, FeedGap, FeedResynced, MintEvicted, DatasetSealed, LlmCallCompleted, BacktestCompleted, StrategyVersionRegistered, ParamsProposed, with NewTokenSeen as an alias view of TokenLaunched); frozen Event with event_id, kind, entity, ts, source_seq, dedup_key, source and typed payload; event_id is the first 32 hex chars of sha256(kind, entity, dedup_key); PRIORITY mapping kind to rank as a pure function of kind; EventPublisher protocol with publish returning PublishResult (accepted, deduped, coalesced, rejected_closed, spilled); HandlerSpec(name, seat, kinds, fn, idempotent=True, max_attempts, base_s, cap_s, deadline_s) with retry jitter from make_rng(run_seed plus crc32(handler name))
- bus: EventBus with subscribe, publish, close(grace_s); per-entity FIFO lanes; P0 never dropped (producer awaits space at the soft bound, one Escalation per outage with free-string kind event_dead_letter or event_backlog); P1 overflow rejected newest to the DLQ with reason overflow; P2 overflow drops oldest and counts; G-01 bounds (max_concurrency 4, priority_workers 2, per-lane 256, P1+P2 total 4096, P0 soft 10000)
- store: EventStore over sidecar sqlite var/events/events.sqlite holding dead letters, dedup keys, cursors and pending events; no ledger writes, ledger reuse is Escalation rows only
- dlq: DLQ list, replay and purge; poison (non-transient handler error) goes to the DLQ; P0 and P1 handlers retry only transient errors (DataStale, ToolTimeout, ToolRateLimited, LedgerUnavailable) with seeded jitter, P0 until deadline_s (exit 60 s); CancelledError always propagates; UNIQUE IntegrityError on the ledger idempotency key counts as success
- cli: pumpgrok events dlq list, dlq replay and dlq purge in src/pumpgrok/cli/events.py, wired through a _VERB_HANDLERS entry in cli/dispatch.py with parsing in cli/parsing.py
