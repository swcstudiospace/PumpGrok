| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-17-02 | Elevation of privilege | kill clear | high | mitigate | Clear requires a human approval record; no engine path clears. Test asserts a non-human clear is refused. |
| T-17-SC | Tampering | pip/uv installs | high | mitigate | No new package; do not run uv add. |

## Test strategy

TDD per task: slice matrix first (at cap, above cap, exactly at cap+1),
kill matrix (buy blocked, exit allowed, non-human clear refused, restart
still blocked), then the pin test. Every test uses an injected Clock and
fixture ledger; no network. Run the risk subset during the task and the
full `make test` only in plan 17-07.

## Rollback

Revert the plan commits in reverse order (pin test, kill, slice); the
engine returns to pre-Phase-17 behaviour on existing rows, so no data
migration is needed and replay hashes return to the Phase 16 values.
