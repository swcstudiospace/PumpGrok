Design to implement (FROZEN after this plan):
- Intent: frozen dataclass with strategy_id, mint, side ("buy" or "sell"), size_lamports (int), decision_id (str), reason (str). No floats for money.
- StrategyContext: frozen dataclass exposing only immutable snapshots: now (from an injected clock), the tick snapshot, and the strategy's own tape snapshot. No store, no clock setter, no ledger handle.
- Strategy: a Protocol with strategy_id (str), BOUNDS (Mapping of key to bound), DEFAULTS (Mapping, values are PENDING OWNER APPROVAL), and on_tick(context) returning a tuple of Intent. Hooks take only the context.
- version_id(params): sha256 over canonical JSON of {strategy_id, params, sha256 of the strategy module source}. It changes when code or params change.
- Registry: a static tuple of strategy classes in fixed order, legacy_screening included with empty BOUNDS. Duplicate ids raise at import. No dynamic loading, no entry points.
- paper-event overlay: copy every value of paper.toml, then set [risk] max_open_positions = 6 and max_trades_per_day = 40. Do not edit paper.toml or live.toml.
</context>
