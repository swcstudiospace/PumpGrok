## Test strategy

Stage matrix first (BACKTEST to PAPER to LIVE_ELIGIBLE on evidence, each
refusal class), then one parametrized looser-than-floor case per floor,
then gate-reuse parity (same evidence, same verdict from upgrade and
promotion), then demotion (hash change, evidence loss, kill present).
Writer discipline asserts a non-writer write raises. All evidence is
fabricated records; no backtest run, no network, fake Clock.

## Rollback

Revert the CLI verb, then demotion, gate parameter, thresholds and stages
last. The stage rows in the ledger are read-only for pre-Phase-17 code,
which ignores them, so reverting is safe mid-run.
