| Operator env/config into inventory | Untrusted input values cross into readiness verdicts |
| Doctor/run output into operator shell | Presence/source reports cross into logs and ledger |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-14-08-01 | Information disclosure | doctor_report.py | high | mitigate | Reports carry presence and source only; sentinel test over stdout, stderr, logs, and ledger file |
| T-14-08-02 | Tampering | validators.py | high | mitigate | Address refusal names the field and never echoes the value |
| T-14-08-03 | Spoofing | access.py | medium | mitigate | Grants exist only as operator-choice ledger rows; default is no grant |
| T-14-08-04 | Elevation of privilege | start_gate.py | high | mitigate | Paper start refuses until required inputs complete and access decisions recorded; empty key counts as missing |
| T-14-08-SC | Tampering | pip/uv installs | high | mitigate | No new package except the Ed25519 check via the existing solders dependency if already present; otherwise a pure-Python curve check with no install |
</threat_model>
